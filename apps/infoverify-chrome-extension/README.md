# InfoVerify — Chrome 扩展骨架

## 功能
- 在网页上右键 -> `核实选中文本或当前页面`
- 默认使用 Chrome 内置本地 AI，并结合 GDELT 最近新闻做交叉验证
- 本地 AI 会按可重复性、交叉验证、内容具体性三原则评分并给出结论
- 可重复性会结合打包在插件里的 MBFC 静态数据与 GDELT 时间线
- 云端 AI 暂时灰度中，仅保留计划入口
- 自动打开 Side Panel 展示核验结果
- 设置页可选择模型输出语言；当前支持英文、西班牙语、日语和中文输出（中文会在本地翻译层生成）

## 安装（开发者模式）
1. 打开 Chrome -> `chrome://extensions`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本目录：
   - `./apps/infoverify-chrome-extension`

## 使用
1. 打开任意网页
2. 右键 -> `核实选中文本或当前页面`
3. 如果你已选中文本：会核实选中文本；否则会使用当前页面正文
4. 在右侧 Side Panel 查看“结论/三原则评分/GDELT 交叉验证/AI 评估”

## 说明
- 首发版无需后端，也不需要配置 API Key
- GDELT 新闻检索会自动在本地 AI 分析前执行
- MBFC 数据文件预留在 `src/data/mbfc.json`，后续只需把静态域名信誉表打包进去即可
- 本地 AI 需要 Chrome 138+，第一次使用可能会先下载模型
- 云端 AI 入口目前仅作为占位，后续再开放
- 本地 AI 的提示词和模型输入统一使用英文；中文输出由本地翻译层补齐
